# Step 3 Cards

USMLE Step 3 flashcards (664 cards, 38 decks) and 44 CCS case drills. One HTML file, works offline, installs to your phone's home screen.

- Live app: https://vettbty.github.io/step-3-cards/
- Progress is stored on each device. Use Info → Export/Import to move it.
- When you publish an update, change `CACHE` in `sw.js` (e.g. `step3-v2`).
